# Design System

## Theme Overview

This design system uses a **light** color mode, providing a bright and clean aesthetic.

## Typography

The typography is consistently set to **Inter** for all elements, including headlines, body text, and labels. This choice promotes a unified and modern reading experience across the interface.

## Shape and Spacing

UI elements feature a **moderate roundedness (2)**, offering a balanced and friendly appearance without being overly soft or sharp. Spacing is set to **normal (2)**, ensuring comfortable readability and visual balance between components.

## Color Palette

The core color palette is defined as follows:
*   **Primary Color:** `#9bcbff` - A soft, light blue, suitable for key interactive elements and branding.
*   **Secondary Color:** `#c3e5c3` - A light green, intended for supporting UI elements and secondary actions.
*   **Tertiary Color:** `#c38fe1` - A light purple, used for accents, highlights, and decorative touches.
